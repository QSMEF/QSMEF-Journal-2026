# QSMEF — Experimental Results

This directory contains the experimental results generated by the QSMEF validator for the five quantum case studies.

## Files

- **applicability_results.csv**: Applicability verdicts, coalition counts, and validation outcomes for the five case studies.
- **shapley_results.csv**: Shapley functional contributions for applicable cases, including efficiency verification.
- **skw_comparison.csv**: Comparison of the original SKW oracle and the modified oracle with phase 0.70π.

## Reproducibility

The results were generated using `qsmef_validatorV1.0.py`, available in the repository root.

To reproduce the experiments, install the dependencies listed in `requirements.txt` and execute:

```bash
python qsmef_validatorV1.0.py
```

All experiments use the configurations and semantic contracts declared in the validator.

## Interpretation

QSMEF computes Shapley functional contributions only when the declared technical, functional, and semantic applicability conditions are satisfied.

Cases classified as not applicable under the declared scope are documented to illustrate the methodological boundaries of the framework.

For further details, see `VALIDATION_REPORT.md` in the repository root.
